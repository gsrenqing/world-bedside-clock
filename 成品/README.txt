World bedside clock 5.6.6（下沿紫边补修 · 双击入口直达）
=====================================================

绿色单文件桌面世界时钟（Windows，无需安装，双击即用）。

5.6.6 版本说明（本轮）
-------------
1. 下沿紫/粉边补修：在 5.6.5 上沿锯齿净化的基础上，继续清理 Black、青花瓷
   外壳下沿残留的轻微紫红/浅粉边。透明底插值判定拆为两支：暗紫红（炭黑壳与
   品红插值的暗紫过渡）、亮浅粉/浅灰紫（白壳边与透明/品红插值的浅色过渡），
   分别按亮度与红绿差量识别；银灰、玫瑰金、青花蓝纹、绿屏本色不受影响。
2. 双击时分直达日期和时间设置：修正原先无法识别、落到控制面板主页的无效设置
   协议，改为直连“时间和语言 > 日期和时间”页。
3. 双击月日直达系统日历：修正日历应用的启动方式（shell:AppsFolder 反斜杠
   分隔、UseShellExecute 解析），不再误开资源管理器；回退顺序为 邮件和日历
   → Outlook for Windows → 日期和时间设置页。

已知限制（本轮未做 / 固有限制）
------------------
· 扩展显示器重新连接后，窗口自动恢复到拔屏前原位：本轮不做，维持现状；
  拔屏回收后统一在主屏居中分列排列。
· 60% 等较小缩放比例下，圆角轮廓在低分辨率下仍可能有轻微像素台阶，属
  抗锯齿固有限制；100% / 90% 比例下边缘平滑。
· 旧“邮件和日历”在部分系统已被 Outlook for Windows 接管，双击月日可能
  打开 Outlook 日历，属系统重定向，并非进入资源管理器。

5.6.5 既有功能（沿用）

6. Black 上沿/轮廓紫边修复：放宽外壳与品红透明底插值产生的暗紫红过渡像素

   日历不可用时回退到日期和时间设置页（具体直达路径见本轮第 2、3 条修正）。

5.6.4 既有功能（沿用）
------------------
8. 多屏拔屏回收：运行实例挂载在主屏之外的扩展显示器上时，一旦该显示器断开
   连接，所有仍在运行的实例自动回到主屏，以主屏中心为轴垂直居中、窗口之间

5.6.3 既有功能（沿用）

    中点由中文字库点阵宋渲染；中文版保持 “中文 / 英文” 三段式。

    · 多个窗口时：关闭当前窗并删除其地点、位置、大小等配置，下次启动不再加载；
    · 仅剩最后一个窗口时：仅暂退后台、保留该窗全部配置；程序退出运行，
      重新加载或电脑重启（若该窗勾选开机自启）时自动恢复显示。

20. 时区规则刷新：每年 5/1、11/1 之后的首次启动，静默重刷一次各窗口时区规则
    （无界面提示）；其余时刻时区跟随 Windows 规则自动切换夏令时/冬令时。

通用功能
--------
- 一城市一窗口一实例，最多 8 个实例；右键「添加地点」新增，
  新实例继承前一实例的样式/大小/透明度/速度/位置（仅位置偏移）。
- 每个实例独立窗口样式、大小（120%~60%）、透明度（100%~10%，每档 10%）、
  置顶层级与桌面位置。
- 鼠标悬停实例时 100% 不透明，移开后恢复设定透明度。
- 所有配置写入注册表，重启自动恢复全部实例；开机自启（偏好持久化，
  关闭后下次启动不会被重新打开）。
- 固定 24 小时制；年份 4 位完整数字；无天气功能。
- Alt+Tab 不显示时钟窗口（仅托盘可见）。
- 改区地点名横向循环滚动字幕（右→左）；右键「文字滚动速度」1~5 档。
- 所有地点中英文对照；中国 30 个自治州标准英文名，
  区县/地级市无英文名时拼音首字母大写兜底。

城市-时区匹配
------------
- 中英文同时匹配：中文走内置中文库（区县/省地级/中英对照表/国家/州省），
  英文走 GeoNames 约 3.3 万城市 + 中英对照表英文名 + 自治州标准英文名；
  多结果弹出点选，未匹配弹手动时区列表兜底。
- 时区跟随 Windows 夏令时规则自动切换。

数据来源
--------
- GeoNames 全球地理数据库（geonames.org），依据 CC-BY 4.0 许可使用。
- 中国行政区划数据源自民政部《中华人民共和国行政区划代码》。
